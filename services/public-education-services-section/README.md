## Research and video publishing

Run from this directory using the repository's package resolver:

```sh
node --import ../../../../../engineering-services-section/services/computer-engineering-services-section/services/computer-code-engineering-services-section/services/javascript-engineering-services-section/services/javascript-node-services-section/scripts/register-house-resolver.mjs src/cli.mjs status all
```

The same entrypoint accepts `research <channel> <lesson>` to prepare a report without requesting a video; `produce [channel|all] [lesson]` fills upcoming publication slots or advances the named lesson; `artifacts <channel>` lists notebook videos; `adopt <channel> <lesson> <artifact-id>` reconciles an uncertain submission; `retry <channel> <lesson>` retries a failed video; and `verify [channel|all]` checks configured YouTube identities. `node --import <resolver> src/authorize.mjs <channel>` connects an account.

To offer observed, expiring account capacity for thumbnails, set `INFERENCE_ACCOUNT_ENTITLEMENTS_FILE` to a local JSON file with an `observations` array. Each observation must record `type: "AccountArtifactEntitlementObservation"`, opaque `accountIdentity`, `providerIdentity`, `product`, `windowIdentity`, `resourceUnit`, `capabilities: ["image-generation"]`, `executionMode: "operator-mediated"`, `zeroCash: true`, `observedAt`, `validUntil`, `expiresAt`, integer `remaining` and `unitsPerArtifact`, and `provenance: {"kind":"operator-ui","reference":"..."}`. Record only capacity and cost actually visible in the account UI; no account credentials belong in this file. `inspect_inference_resources` shows these observations separately from API providers.

When a current observation can serve a lesson thumbnail, `produce` writes an operator packet to the channel's ignored `.work/<lesson>/thumbnail-work.json` and pauses. Complete the packet in the named product, then run `adopt-thumbnail <channel> <lesson> <downloaded-image> <spent-units>` through the same CLI. Adoption checks the source hashes, records the returned image hash and operator-reported spend in `production/episodes/<lesson>/thumbnail-receipt.json`, fits the publication JPEG, and lets the next `produce` run continue. If the product refused or the packet expired without an artifact, update the observation and run `release-thumbnail <channel> <lesson> <expired|logged-out|quota-exhausted|ui-changed|operator-declined>` before retrying. The released packet is retained for reconciliation. Without a current observation, the existing image generator continues automatically.

Production automatically selects unpublished curriculum lessons to maintain two upcoming videos per enabled channel, counting work already in progress. It uses publication history and live YouTube inventory to avoid repeating videos. When the curriculum is exhausted, it appends distinct lesson questions based on the course and existing topics. `produceVideo: true` remains an explicit commissioning option. Research produces Markdown reports and adjacent source/search evidence in the curriculum. The inference engine owns report drafting and admission; Gemini Notebook owns recoverable report-to-video production; media engineering owns raster fitting and audio extraction. This education workflow supplies curriculum prompts, channel artwork direction, publication slots, and the composition of those capabilities with transcription and YouTube publishing. Reports can also feed articles and books.

Existing channel `production/episodes/<lesson>/state.json` and `record.jsonl` retain progress and provenance. Downloads and resumable upload URLs stay in each channel's ignored `.work/` directory. A submitted report cannot be silently replaced; uncertain video submissions retain their exact checkpoint until their provider outcome can be reconciled. Credentials load from this directory's `.env` and ancestor `.env` files without overriding the process environment. `scripts/transfer-auth-profile.mjs restore|save notebook|codex` carries the local Gemini Notebook or Codex profile through `NOTEBOOKLM_AUTH_JSON` or `CODEX_AUTH_JSON`; encrypted snapshots live in this package's `state/` directory. The education wrapper keeps the legacy `youtube-notebook` and `youtube-codex` encryption namespaces so existing snapshots remain readable.

The local `content/systemd/youtube-production.timer` runs production every twenty minutes; its service then runs `scripts/checkpoint.mjs` to retain production state, reports, and curriculum additions in Git. Link both units with `systemctl --user link` and enable the timer. The obsolete GitHub workflow that invoked removed production commands has been retired; production runs on the host with the provider logins. Install Gemini Notebook through its provider package and make ffmpeg/ffprobe available on PATH.
