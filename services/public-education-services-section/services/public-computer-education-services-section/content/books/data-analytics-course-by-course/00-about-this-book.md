# About this book {.unnumbered}

This book is a study companion for people taking Google's Data Analytics
Professional Certificate on Coursera. It follows the certificate course by
course. For each course it states what you should be able to do when you
finish, teaches the ideas through one running example with formulas and code
you can type yourself, and then asks you to recall them before it shows you
the answers.

It's for you if you're taking the certificate, deciding whether to, or
finished it and want a compact review before interviews. It assumes no
background in statistics or programming.

## An independent companion

**This book is independent. It isn't affiliated with, endorsed by or
sponsored by Google or Coursera.** "Google" is a trademark of Google LLC,
"Coursera" of Coursera, Inc., and "Tableau" of Salesforce, Inc. The book names
them only to say which credential and tools it's a companion to.

It doesn't reproduce the course's videos, readings, quizzes or graded work,
and it can't stand in for them. You earn the certificate by completing the
courses. The book teaches the same subject from the original sources the
field is built on and asks its own questions.

does this book. If you hold older course materials that use R, the ideas in
Chapter 7 carry over; only the syntax differs.

## The running example

> **Maple County Library.** A county library system has five branches.
> Weekend visits across the system fell compared with the year before, and
> the library's board wants to know why before it sets next year's hours.
> The library has daily visit counts from each branch's door counter, its
> checkout records, a list of each branch's opening hours, and a patron survey.

Every chapter works on this question, from asking it well to presenting the
answer.

## How to use this book

The book is built on two findings from learning research. Recalling
something from memory strengthens it more than rereading it
[@roediger2006]. Reviews spread out over time beat the same reviews crammed
together, and the best gap grows with how long you need to remember
[@cepeda2006]. A large review of study techniques rated these two, practice
testing and spaced practice, the most useful of the ten it examined, and
rated rereading and highlighting among the least [@dunlosky2013].

Each chapter opens with **What you will be able to do** and ends with
**Check yourself** questions and their **Answers**. Answer on paper before
you look, then come back to the same questions a few days later and again
after a week or two; the study plan lays out a schedule. Type every formula
and query yourself: data skills are learned by doing them.

## What this book doesn't do

- It doesn't grant, or count toward, the Google certificate.
- It doesn't give you the course's practice data sets or its hosted tools;
  you'll need a spreadsheet program, a SQL environment, Tableau Public and
  a Python notebook, as the course provides or recommends.
- It covers the ideas in each course, not every example or reading.
- It reflects the courses as described on 27 September 2026. If a course has
  changed, trust the course.
