# Formulas and lists to know {.unnumbered}

A one-page review of what the exam expects you to recall exactly. Cover the
right-hand column and test yourself.

## Formulas

| Name | Formula | Reading |
|---|---|---|
| PERT expected duration | (o + 4m + p) / 6 | Weighted toward the most likely |
| Total float | LS − ES, or LF − EF | Zero on the critical path |
| Schedule variance | SV = EV − PV | Negative: behind |
| Cost variance | CV = EV − AC | Negative: over budget |
| Schedule performance index | SPI = EV / PV | Below 1: behind |
| Cost performance index | CPI = EV / AC | Below 1: over budget |
| Estimate at completion | EAC = BAC / CPI | Current cost performance continues |
| | EAC = AC + (BAC − EV) | Variance was a one-off |
| | EAC = AC + (BAC − EV) / (CPI × SPI) | Cost and schedule performance both persist |
| Estimate to complete | ETC = EAC − AC | Still to spend |
| Variance at completion | VAC = BAC − EAC | Negative: forecast over budget |
| To-complete performance index | TCPI = (BAC − EV) / (BAC − AC) | Efficiency needed to finish on budget |
| Little's law | Lead time = WIP / throughput | Less WIP, faster delivery |
| Forecast sprints remaining | Remaining points / velocity | |

## Lists

- **Process groups:** initiating, planning, executing, monitoring and
  controlling, closing.
- **Knowledge areas:** integration, scope, schedule, cost, quality, resources,
  communications, risk, procurement, stakeholders.
- **PMBOK 7 principles:** stewardship, team, stakeholders, value, systems
  thinking, leadership, tailoring, quality, complexity, risk, adaptability and
  resiliency, change.
- **PMBOK 7 performance domains:** stakeholders, team, development approach
  and life cycle, planning, project work, delivery, measurement, uncertainty.
- **Code of ethics values:** responsibility, respect, fairness, honesty.
- **Life cycles:** predictive, iterative, incremental, adaptive, hybrid.
- **Threat responses:** escalate, avoid, transfer, mitigate, accept.
  **Opportunity responses:** escalate, exploit, share, enhance, accept.
- **Dependencies:** finish-to-start, start-to-start, finish-to-finish,
  start-to-finish; mandatory, discretionary, external, internal.
- **Schedule compression:** crashing (adds cost), fast tracking (adds risk).
- **Cost of quality:** prevention and appraisal (conformance); internal and
  external failure (nonconformance).
- **Communication methods:** interactive, push, pull.
- **Conflict modes:** competing, collaborating, compromising, avoiding,
  accommodating.
- **Scrum:** Product Owner, Scrum Master, Developers; Sprint, Sprint
  Planning, Daily Scrum, Sprint Review, Sprint Retrospective; product backlog
  (product goal), sprint backlog (sprint goal), increment (definition of
  done).
- **Scrum values:** commitment, focus, openness, respect, courage. **Pillars:**
  transparency, inspection, adaptation.
- **XP values:** communication, simplicity, feedback, courage, respect.
- **Kanban practices:** visualize, limit WIP, manage flow, make policies
  explicit, implement feedback loops, improve collaboratively.
- **Requirement types:** business, stakeholder, solution (functional,
  nonfunctional), transition.
- **MoSCoW:** must, should, could, won't have this time.
- **INVEST:** independent, negotiable, valuable, estimable, small, testable
  [@wake2003].
- **Tuckman:** forming, storming, norming, performing [@tuckman1965];
  adjourning, added later [@tuckman-jensen1977].
