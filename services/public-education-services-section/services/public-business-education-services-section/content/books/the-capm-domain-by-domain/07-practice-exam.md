# A practice exam

*Covers all four domains, in the outline's proportions. Before you start:
Chapters 1 to 6.*

## What you will be able to do

- Answer 40 questions across all four domains in 48 minutes, the real exam's
  pace of 72 seconds a question.
- Find, from your results, the domains and tasks you still need to study.

## How to take it

Set a timer for 48 minutes. Answer on paper, without the book, in one
sitting. Don't look anything up. Mark any question you guessed.

The questions follow the outline's weights [@pmi-capm-eco-2023]: 14 from
Domain 1 (36%), 7 from Domain 2 (17%), 8 from Domain 3 (20%) and 11 from
Domain 4 (27%), mixed as on the real exam. Every question was written for
this book; none comes from a PMI exam.

## Scoring

PMI doesn't publish a passing percentage for the CAPM. After the exam it
reports your performance in each domain against a target. This book's own
rule of thumb, not PMI's: if you score below 75 percent in any domain here,
or guessed on more than a few questions in it, restudy that domain's
chapters and retake its Check yourself questions before your exam.

Each answer below names its domain and task, so you can total your score by
domain.

## Check yourself

## Answers

1. **C.** Domain 1, Task 1. Ongoing, repeated work is operations.
2. **D.** Domain 3, Task 4. The Product Owner orders the backlog.
3. **B.** Domain 2, Task 2. Paths: A–B–D = 4 + 6 + 2 = 12; A–C–D = 9. The
   longest path sets the duration.
4. **C.** Domain 4, Task 3. Surveys reach many people across distance
   quickly.
5. **B.** Domain 1, Task 2. A milestone is a point with no duration; the
   others are activities.
6. **C.** Domain 1, Task 3. The sponsor authorizes and funds; the others are
   the project manager's or the team's.
7. **B.** Domain 3, Task 1. Uncertain requirements and frequent feedback
   favor adaptive.
8. **B.** Domain 2, Task 3. CV = EV − AC = 50,000 − 55,000 = −$5,000: over
   budget. D is the CPI, not the variance.
9. **A.** Domain 4, Task 1. The process manager runs the process; the owner
   is accountable for it.
10. **D.** Domain 1, Task 1. Believed true without proof, for planning.
11. **A.** Domain 1, Task 5. Brainstorming generates many ideas quickly.
12. **D.** Domain 4, Task 6. Acceptance criteria, definition of done and the
    product owner's acceptance.
13. **C.** Domain 3, Task 2. 240 / 30 = 8.
14. **B.** Domain 1, Task 4. Follow the planned response.
15. **C.** Domain 2, Task 1. Fixed, approved designs and a hierarchical
    structure fit a predictive approach.
16. **A.** Domain 4, Task 2. A decision needs interactive communication with
    the decision-makers.
17. **B.** Domain 1, Task 3. Motivating toward a direction is leadership.
18. **C.** Domain 2, Task 2. (4 + 4 × 7 + 16) / 6 = 48 / 6 = 8.
19. **A.** Domain 3, Task 3. Burnup charts track adaptive progress; the
    others are predictive artifacts.
20. **B.** Domain 4, Task 4.
21. **A.** Domain 1, Task 2.
22. **C.** Domain 1, Task 1. Honesty and responsibility require reporting;
    A and B hide it; D skips due process.
23. **D.** Domain 3, Task 5. Without it the product can't launch.
24. **B.** Domain 2, Task 3. SPI = EV / PV = 0.8, behind schedule. D is the
    schedule variance.
25. **C.** Domain 4, Task 3. Use cases capture alternate and error paths.
26. **A.** Domain 1, Task 3. Noticing an emotion is self-awareness;
    managing it is self-regulation.
27. **B.** Domain 3, Task 4. Test-driven development is an XP practice.
28. **D.** Domain 4, Task 5.
29. **D.** Domain 1, Task 2. Formal acceptance comes before closure.
30. **D.** Domain 2, Task 1. Creating the WBS is a planning process.
31. **A.** Domain 4, Task 6. B describes the definition of done.
32. **C.** Domain 1, Task 1. Both approaches in one project make it hybrid.
33. **A.** Domain 3, Task 2.
34. **C.** Domain 4, Task 1. Regulators are outside the performing
    organization.
35. **C.** Domain 1, Task 5. Agendas, timekeeping and owned action items
    make meetings effective.
36. **D.** Domain 2, Task 2. Total float = LS − ES = 9 − 5 = 4.
37. **C.** Domain 3, Task 1. The organization's own repository is an OPA;
    the others are EEFs.
38. **B.** Domain 4, Task 2.
39. **A.** Domain 1, Task 4.
40. **B.** Domain 4, Task 4. A dependent feature can't ship before what it
    depends on.
