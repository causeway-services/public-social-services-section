## The five filed contradictions

Five places in this corpus disagree with themselves, or with the actual formal record, closely enough to matter, and this book has flagged each one where it arose rather than smoothing it into false continuity.

1.  **Fifth-turn versus sixth-turn (Chapter 7).** The 2026-07-19 note that built the actual bridge theorem between the disclination and the KCBS pentagon is explicit that the identification of the disclination’s own sixth-turn conserved rotational quantity with the KCBS pentagon’s fifth-turn D5 obstruction is a named, unready blueprint node, `thm:dervish-protected-holonomy`. The 2026-07-25 “Relational Physics of Coordination” note states the identification as settled fact, without that hedge. This book follows the 2026-07-19 note, because it is the carrier that actually built the theorem in question and stated its own limits.

2.  **J26 rotation orders misattributed (Chapter 6).** The same 2026-07-25 note asserts that “the J26 solid possesses symmetries of order 2, 3, and 4, which satisfy the crystallographic restriction.” `Obsmetrologia/AperiodicOrder/Tiling/J26.lean` was read in full for this book and contains no such theorem; it proves an oriented combinatorial boundary, a quarter-turn identity, a vertex/edge/face count, and a dimension-drop fact, and nothing about rotation order. This book states the claim as false as stated and cites the module directly.

3.  **The Landauer weld graded oppositely (Chapter 9).** “The Price of Saying” and “The Distal Bypass,” two notes written the same day, both state plainly that the coordination-cost bit count is proved in Lean while its weld to physical joules is not. The Distal Bypass’s own appended, informally written transcript section then treats “the identification Landauer equals H^1” as settled and calls the resulting device a “thermodynamic warranty” — directly against the note’s own formal section, written above it in the same file. This book follows the formal section in both notes, and a later research note (2026-07-24) independently confirms that reading, grading the weld OPEN and “explicitly missing” in this book’s own vocabulary.

4.  **The CALM biconditional treated as settled (Chapter 8).** `CRDTCohomologicalCALM.lean` proves four separate convergence facts as a conjunction — each holds outright in the one modal-lattice model the module examines — and is explicit, in its own documentation, that the general CALM biconditional between vanishing cohomology and coordination-free convergence is a distinct, unproved, and separately named open frontier, `thm:calm-convergence-equivalence`. A reader who takes `calm_convergence_facts` as proof of the general biconditional has assumed exactly what the module itself declines to claim. This book states the conjunction as proved and the biconditional as open, because that is what the module’s own text says.

5.  **Two live copies of the projection note (Chapter 3).** The current Obsmetrologia copy of `why-predication-is-not-simply-fregean.md` states explicitly that its projection theorem — classical logic as what remains once predication’s extra structure is projected out — “belongs to the lab’s predication program” and must not be misattributed to a generic curriculum. A legacy copy of the identical mathematics, kept in the relationality section’s archive, instead frames the same content as “what current graduate students of bilattice-valued categorical logic are expected to know,” erasing the claim’s actual authorship. This book follows the current copy, both because it is the version live in the Obsmetrologia documentation tree and because it directly forecloses the framing the legacy copy uses.

## Closing

This book has tried to hold one discipline from its first page to this one: a claim is only as strong as the carrier behind it, named exactly. Some of what this book describes is machine-checked mathematics that will still be true when every person who worked on it has moved on to something else. Some of it is running code that a reader can go execute today. Some of it is a research program’s own honest description of where it has not yet gotten. And a little of it is one person’s words, quoted because they are the words that started all of it, and because a book about honesty in grading claims owes its founder the same honesty it demands of its mathematics: not a mystical origin story, but an actual, dated, imperfectly spelled log entry, doing real work.
