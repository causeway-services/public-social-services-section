# TTI Zelo programmable-response adapter

This adapter turns the public, declarative TTI command directory into a
transport-free `ProgrammableCommunityResponseProgram` for Zelo shadow review.
It does not read Discord, inspect members, retain event content, execute a
response, mention anyone, or alter the established `#dock` and
`#channel-visas` reaction journey.

Each command carries a public source reference and the human office that owns
its accuracy. An application must separately admit, authorize, execute, and
receipt any live response.
