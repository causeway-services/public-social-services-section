# Okaga

A region of the [emsean paracosm](../README.md). Older than the code-side
work on Teraum: Okaga shows up first in stories and fictions
(`triage/content/.../the-okaga.md`, `triage/content/.../emsenn-net-2020-05/content/fictions/the-okaga.md`)
and in the older racket-mud user guides as a referenced setting.

This directory will hold Okaga material extracted into the markdown+YAML
schema, drawing primarily from the existing prose rather than from
engine-side data (which barely exists for Okaga).

## Layout

- `places/` — areas, regions.
- `beings/` — peoples, characters.
- `things/` — objects, artifacts.
- `terms/` — Okaga-local vocabulary.
- `texts/` — Okaga-local prose, including the original "the Okaga" story
  and any others.

See [the schema](../../SCHEMA.md) for entry conventions.
