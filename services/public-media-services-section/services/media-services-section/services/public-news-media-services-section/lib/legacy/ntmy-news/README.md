# _NTMY News_
_An unlicensed news source._

_NTMY News_ is an open-source news outlet in **early alpha**.

## Read the _News_

To read the news, visit [ntmynews.com](http://ntmynews.com). _(That website is built automatically by Github from the master branch of this repository hosted on [Github](http://github.com/samjoneshouse/ntmy-news).

## Write the _News_

Contributions to _NTMY News_ are welcome. Again, this project is in **early alpha**, so things are rough. But below is roughly the process.

### Submit an Issue
If you think there needs to be an article on a topic, please create an [Issue](https://github.com/samjoneshouse/ntmy-news/issues/new). Give it the **article** tag, and add it to the **articles** project. Write a description of what you think the article would be. Try to be thorough enough that someone else familiar with the topic could also contribute.
