***InfraWatch*** is an idea for a blog run by [Josh Blevins](/agents/josh-blevins/) that focuses on infrastructure.

## Regional Focus

InfraWatch is mostly focused on the following regions, but can publish anything related to infrastructural changes.

- Duluth
- North Shore
- Minnesota
- Great Lakes
- Midwest
- United States
- North America
- Western Hemisphere
- Northern Hemisphere
- Earth

## Publishing

I think it should be published on Hive so we can make claims about like, the InfraWatch itself being part of infrastructure, putting information about infrastructure stuff up where it can't easily be removed.
